# Ten- and twenty-year long-range ecosystem scenarios v0.1

**Planning role:** **Long-range ecosystem scenarios / lifecycle outlook and stress test** — **not** a budget, forecast, promise, approved plan, or current funding request.  
**Confidence:** **Low.** Highly sensitive to adoption, scope, technology, jurisdiction participation, inflation, and institutional design.  
**Hierarchy:** Primary external planning horizons are the **18–24-month validation program** (`14`) and the **five-year first-wave ecosystem plan** (`11`). Years 6–10 are **strategic outlook only** (detailed rolling plan around Year 3). Years 11–20+ are **directional lifecycle scenarios**. See rolling-planning policy in `17`.  
**Companions:** `13-ten-and-twenty-year-program-cost-v0.1.csv` · `13-annual-cashflow-base-v0.1.csv` · `13-ten-and-twenty-year-program-cost-v0.1.meta.json`.  
**Database:** Unchanged. App Draft Budget remains **0** / draft / demonstration / unapproved / unpublished.

**Method:** Start from the inventory (`12`) and the reconciled five-year first-wave model (`11` ~$37.5B base). Expand using explicit scale drivers (jurisdictions, institutions, operators, domain maturity, ops, assurance, replacement). **Do not** treat any grand total as predetermined destiny.

**Framing:** Scenario totals are **worldwide ecosystem investment** across many parties — not money controlled by one organization. They have **not** been accepted by governments, funders, or institutions.

**Archetypes (do not use one average blindly):** large federal state · mid-size unitary · small island / microstate · regional bloc overlay · mega-city authority · indigenous nation interface · humanitarian emergency authority · regulated private institution (hospital, bank, university).

## 6. Continuity-to-completion policy

**Principle:** Do not start irreversible production obligations without credible funding to operate, secure, support, and transition them.

### 6.1 Stoppable vs committed work

| Work class | Funding posture |
| --- | --- |
| Research, standards, sandboxes (≤ M2) | Limited, safely stoppable |
| Reference implementations (M3) | Stoppable with archive of artifacts |
| Institutional pilots (M4) | Requires funded exit/transfer plan before start |
| Limited production (M5+) | Requires **committed continuation** package (below) |

### 6.2 Minimum commitments before irreversible production

| Element | Planning floor (base, order-of-magnitude) |
| --- | --- |
| Minimum legally committed funding (multi-year instruments) | Enough to cover **ops + IR + support + assurance** for claimed scope through at least **N+2 years** (N = go-live) |
| Minimum cash / escrow | ≥ **12–24 months** protected operating runway for production scope |
| Protected operating runway (core + operators touching production) | Continuity floor from `11`: **~$2–4B** class before first irreversible multi-J production tranche |
| Safe-pause cost | Funded freeze: read-only mode, security patches, user notices, data export — typically months of ops, not zero |
| Orderly transfer / decommission cost | Escrowed **transfer or wind-down** budget (operator handoff, record export, key destruction ceremony) |
| Independently valuable outputs if next stage unfunded | Published standards, reviewed references, conformance suites, pilot evaluation reports |

### 6.3 Consequences of stopping mid-production

- Rights-impacting services must degrade to **safe pause** or **jurisdictional takeover**, never silent abandonment.  
- Operators retain removal/transfer duties under certification.  
- Public honesty statement required (scope that ended; data disposition).

## 7. Full-program funding views (not one wallet)

Ecosystem totals **must** be reported by responsible party:

| Party | Role in long horizon |
| --- | --- |
| Civizen core organization | Shared fabric, stewardship, co-finance shares |
| Independent governance & assurance | Ring-fenced oversight and audits |
| Operators | Regional/app data-plane ops |
| Jurisdictions | Deployment, legal authority, local support |
| Public institutions | Legacy migration, authoritative registers |
| Private / regulated institutions | EHR, banks, insurers, employers, etc. |
| Research & standards organizations | Domain frameworks, metrology, open science |
| Local implementation partners | Delivery capacity |
| **Total worldwide ecosystem** | Sum of the above — **not** core P&L |

Also report **by domain** (framework vs deployment) using inventory parent domains — without double-counting shared-core.

Illustrative Year 1–20 base split (planning sketch, not accounting): core-primary share remains a **minority** of ecosystem totals as J/institutional/ops dominate later decades.
