# Funding readiness memorandum v0.1

**Audience:** Project owner and delegated stewards.  
**Purpose:** Reconcile canonical funding levels, state the immediate ask, define tranches, record **provisional owner approval decisions**, and hold the **rolling-planning policy**.  
**Not:** An approved operational budget, funding commitment, publication of the Draft Budget, or authorization to accept funds.  
**App DB:** Ordinary Budget centers validation subprogram draft; obsolete Draft Budget demonstration fixture retired from ordinary use. This memorandum does not create ledger commitments or accept funds.

---

## 1. Planning hierarchy (owner)

1. **Detailed operating plan:** 18–24-month validation and institutional-formation program (`14`).  
2. **Primary program plan:** five-year first-wave ecosystem plan (`11`).  
3. **Years 6–10:** strategic outlook only — convert into a detailed rolling plan around Year 3.  
4. **Years 11–20+:** directional lifecycle scenario and risk test — **not** a budget, forecast, promise, or current funding request (`13`).

**External inquiry framing:** Civizen currently maintains a detailed 18–24-month validation plan and a preliminary five-year first-wave ecosystem plan. Longer horizons are retained as internal scenario analysis and will be replaced by rolling plans as evidence develops.

## 6. Rolling-planning policy (canonical)

This is the **single** home for cadence policy; other docs should reference this section rather than restating it.

| Cadence | Action |
| --- | --- |
| **Quarterly** | Review the active **18–24-month** validation / operating plan and working estimate |
| **Annually** | Refresh the **five-year** first-wave program plan |
| **Around Year 3** | Begin formal **Years 6–10** detailed rolling planning (today: strategic outlook only) |
| **Before major Years 4–5 obligations** | Seek post–Year-5 operating and transition commitments |
| **When material evidence changes** | Revise long-range lifecycle scenarios (`13`) |
| **Always** | Preserve prior versions for audit and learning |

**In-app:** Settings → Funding → **Program plan** shows read-only generated summaries (estimates/scenarios). **Budget** remains the operational, potentially approvable ledger. Do not mix the two.
