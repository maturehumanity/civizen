# Governance

This folder contains the rules that keep documentation, content classification, certification, and contribution authority aligned.

Start with `content-collaboration-model.md` when adding or reviewing new content types.

Use `decentralized-transition-architecture.md` for the roadmap that moves Civizen from founder/admin-controlled operations toward citizen-verifiable governance.
