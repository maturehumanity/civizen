# Proposals

Home for unfinished or in-flight documentation proposals. Do not treat drafts as current policy.

## Status directories

| Directory | Use |
| --- | --- |
| [`drafts/`](./drafts/) | Early drafts and redesign notes |
| `under-review/` | Create when a proposal enters review |
| `accepted/` | Create when accepting; then move content to the canonical section |
| `rejected/` | Create when retaining a rejected proposal for history |

Empty status directories are omitted until needed.

## How to propose a change

1. Add a Markdown draft under `drafts/` with front matter (`title`, `status: draft`).  
2. Link related canonical docs; do not fork a second editable canonical copy.  
3. After acceptance, place the final document in `00`–`05` and leave only links or archive stubs here.
